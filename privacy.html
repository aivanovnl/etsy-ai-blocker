Privacy Policy — AI Filter for Etsy

Last updated: September 2026

This extension collects no personal data and sends no data anywhere about you or your browsing.

What it stores

Your settings (enabled/disabled, sensitivity level, hidden-item counts, and any shop names you personally add or un-hide) are stored using Chrome's local storage (chrome.storage.local) — on your device only. Nothing is synced to a server, and nothing is shared with the developer or any third party.

What it fetches

Once a day, the extension fetches one public, static file — a shared list of known shop names — from this project's GitHub repository (raw.githubusercontent.com/aivanovnl/etsy-ai-blocker). This request carries no information about you: it's the same static file for every user, requested anonymously like loading any public webpage.

What it doesn't do

  • No analytics, tracking pixels, or telemetry of any kind
  • No account, sign-up, or login
  • No browsing history collection
  • No data sold or shared with advertisers

Permissions explained

  • storage — to remember your settings locally
  • alarms — to schedule the once-a-day blocklist refresh
  • Etsy.com access — to read listing titles/prices on search pages so the filter can score them; the extension never reads or modifies anything outside etsy.com

Contact

Questions about this policy: open an issue at github.com/aivanovnl/etsy-ai-blocker.
